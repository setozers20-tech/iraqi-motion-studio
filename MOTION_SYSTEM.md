IRAQI MOTION STUDIO

Motion Graphics Production Standards

1. Project Mission

Build professional, content-aware motion graphics using HTML, CSS and JavaScript.

The system must produce visually sophisticated animations, not generic templates or random decorative effects.

2. Core Principles

- Every animation must serve the spoken content.
- Synchronize visual events with audio and narration.
- Preserve the original identity and appearance of people.
- Never distort faces, photographs or reference images.
- Maintain consistent visual identity throughout each video.
- Avoid repetitive, primitive or unnecessary transitions.

3. Motion Design Quality

- Professional typography and visual hierarchy.
- Carefully designed compositions.
- Smooth and natural easing curves.
- Meaningful transitions.
- Sophisticated kinetic typography.
- Appropriate depth and spatial movement.
- High-quality visual storytelling.

4. Technical Requirements

- HTML, CSS and JavaScript.
- Responsive design, especially mobile screens.
- Accurate video and audio duration synchronization.
- No overlapping or disappearing elements.
- Clean and maintainable code.
- Efficient rendering and animation performance.

5. Quality Assurance

Before approving any project:

1. Check JavaScript errors.
2. Verify all visual assets.
3. Test animation timing.
4. Inspect transitions and typography.
5. Verify audio synchronization.
6. Inspect the actual rendered result.
7. Fix all identified issues before delivery.

6. Development Workflow

1. Analyze the source video and audio.
2. Build a detailed scene-by-scene timeline.
3. Define the visual direction.
4. Design the motion system.
5. Generate the complete implementation.
6. Test and inspect the rendered output.
7. Improve until the visual quality meets professional standards.

7. Non-Negotiable Rule

A project is not successful simply because its code runs without errors.

Visual quality, storytelling, synchronization and motion design are equally important.
